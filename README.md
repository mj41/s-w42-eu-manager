# s-w42-eu-manager

The home manager for Stackchan robots in Embody Mode: it runs on a computer at home, sets robots
up over USB, keeps a live line to them, switches their apps, and checks the robots' tokens for the
apps running at home. Everything here works without the cloud.

The code is moving here now from the manager that runs [sm.w42.eu](https://sm.w42.eu), split into
this public home manager and sm.w42.eu's own part (sign-in, users, linked homes).
