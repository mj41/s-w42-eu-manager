Stackchan manager

This manager has no sign-in: open it on the computer it runs on (http://localhost:…), or scan the QR code on a robot's Manager screen (the gear on its app switcher) with this phone.

Stack-chan (スタックチャン) is a registered trademark of Shinya Ishikawa; this project is independent and only made to work with Stack-chan robots.
